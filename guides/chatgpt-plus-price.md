# ChatGPT Plus 多少钱？价格、税费与汇率怎么看

> OpenAI 资料最后核对：2026-09-01。价格可能变化，请以 OpenAI 结算页面为准。

## 直接答案

OpenAI 当前官方说明显示，ChatGPT Plus 的基础价格为 **20 美元/月，按月计费**。用户最终支付金额可能受到当地税费、结算币种、汇率以及发卡行费用影响，因此银行卡账单上的人民币金额不一定等于按即时汇率简单换算的数字。

官方价格入口：[OpenAI Docs 定价说明](https://learn.chatgpt.com/zh-Hans/docs/pricing)

## 当前公开套餐怎么理解

| 套餐 | 当前公开价格 | 主要功能区别 |
| --- | ---: | --- |
| Free | $0/月 | 体验简短编程任务，模型、功能和用量有限制 |
| Go | $8/月 | 面向轻量级编程任务 |
| Plus | $20/月 | Web、CLI、IDE 扩展和 iOS；自动代码审查、Slack 集成、GPT-5.6 模型系列 |
| Pro 5x | $100/月 | 包含 Plus 的 GPT-5.6 Sol、Terra、Luna 与其他功能；Codex 用量约为 Plus 的 5 倍 |
| Pro 20x | $200/月 | 包含 Plus 的 GPT-5.6 Sol、Terra、Luna 与其他功能；Codex 用量约为 Plus 的 20 倍；无限桌面语音 |
| Business | $20/用户/月起 | 团队工作区、管理控制、SAML SSO 和 MFA；年付起价且至少 2 位用户 |

Enterprise 与 Edu 通常需要联系销售。Pro 20x 的“无限语音”不代表 Codex 任务无限：通过语音发起的任务仍会消耗 Codex 用量。ChatGPT 订阅和 API 是两套计费系统，Plus、Go 和 Pro 都不包含 API 使用额度。

## Pro 5x 和 Pro 20x 有什么区别

OpenAI 当前定价说明把 Pro 分成两个用量档位：

- **Pro 5x（$100/月）**：Codex 用量约为 Plus 的 5 倍；桌面语音约为每个 5 小时窗口 1–2.5 小时。
- **Pro 20x（$200/月）**：Codex 用量约为 Plus 的 20 倍；桌面语音可无限使用，但语音启动的任务仍计入 Codex 用量。

两档都包含 Plus 的 GPT-5.6 Sol、Terra、Luna 模型系列及其他功能。实际消息数量还会受到模型、任务复杂度、上下文、工具调用和是否在云端运行等因素影响。

## 为什么每个人看到的金额可能不同

常见差异来自以下几项：

1. **税费。** 部分地区会在基础价格之外收取适用税费。
2. **本地币种。** OpenAI 在部分地区提供本地币种结算，具体显示取决于结算页面。
3. **银行卡汇率。** 发卡行采用的入账汇率可能与搜索引擎显示的即时汇率不同。
4. **跨境费用。** 个别银行可能收取货币转换或跨境交易费用。
5. **购买渠道。** 网页、Apple App Store、Google Play 或第三方服务的价格结构可能不同。

OpenAI 关于本地币种的说明：[Multi-currency billing](https://help.openai.com/en/articles/10421635-multicurrency-billing)

## 付款前应该核对什么

- 套餐名称是不是 ChatGPT Plus，而不是 API 余额或其他产品；
- 账单周期是按月还是其他周期；
- 页面显示的币种和最终金额；
- 是否存在自动续费；
- 取消、退款和售后由谁负责。

如果通过第三方订阅服务，不应把第三方报价描述成“OpenAI 官方价格”。它包含的服务成本、支付便利性和售后范围可能不同，需要单独比较。

## 本项目的推荐原则

能够通过官方渠道完成付款时，优先选择官方渠道。官方支付条件受限时，再评估第三方服务的实时价格、隐私政策、退款规则和账号风险。不要只因为价格低就忽略服务主体和信息安全。
