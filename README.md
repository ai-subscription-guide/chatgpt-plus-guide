## ChatGPT Plus 付款失败怎么排查

按照下面顺序检查：

1. 确认卡号、有效期、安全码、姓名、邮编和账单地址准确。
2. 确认账户余额充足，发卡行允许国际线上交易和循环扣款。
3. 完成银行要求的 3D Secure 或其他身份验证。
4. 确认付款方式和发卡地区符合服务支持条件。
5. 不要通过虚假资料绕过地区限制；仍然失败时联系发卡行或查看官方帮助。

官方排查：[Why was my credit card declined?](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)
